# Minisheet

[Minishit](https://ashishpatelengineering.github.io/minishit/) is a minimal spreadsheet in a single HTML file. No build step, no server, no dependencies.

- Formulas (no `eval`): `SUM`, `AVERAGE`, `IF`, `VLOOKUP`, `SUMIF`, date functions, and more
- Dates, sorting, insert/delete rows and columns, column widths, undo/redo
- Copy and paste with Excel and Google Sheets, open and export CSV
- Light and dark mode
- Autosaves in your browser. Nothing leaves your device.

## Use it

Open `index.html` in a browser, or host it on GitHub Pages:
Settings, Pages, deploy from the `main` branch, `/ (root)`.

## Your data

Data is stored in your browser on each device. It does not sync, and clearing site data erases it.
Use **Save** to download a `.json` backup that keeps formulas and formatting, and **Open** to load it again.
**CSV** exports computed values.
